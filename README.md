# 🎓 AI University Admission Advisor

A beginner-friendly **Multi-Agent University Admission System** built using **CrewAI, Groq LLM, and Streamlit**.

The system analyzes student qualifications, checks admission requirements, evaluates eligibility, and recommends suitable university degree programs.

## 🚀 Features

- **Admission Requirement Checking:** Extracts program requirements from a sample university dataset.
- **Eligibility Evaluation:** Compares student marks, qualifications, and subject prerequisites with admission criteria.
- **Program Recommendations:** Suggests suitable degree programs based on eligibility and academic interests.
- **Interactive Web Interface:** Students can enter their information using Streamlit.
- **AI-Powered Analysis:** Uses Groq's `openai/gpt-oss-120b` model.
- **Downloadable Report:** Generates admission recommendations in Markdown format.
